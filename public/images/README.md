# Product imagery

This folder holds the storefront's product art. The site ships with **21
self-authored SVG illustrations** generated by:

```bash
npm run gen:images   # regenerates every *.svg from scripts/generate-images.mjs
```

They are rendered through `next/image` (`components/ProductImage.tsx`) and
referenced by `image` fields in `data/jewelleryData.ts`.

## Using real photography

To replace the illustrations with real HD photos, either:

1. **Keep the filenames** — drop `necklace.jpg`, `ring.jpg`, etc. here and
   update the matching `image:` paths in `data/jewelleryData.ts` (or just
   overwrite the `.svg` files); or
2. **Point the data at new files** — set each product's `image` to your new
   asset path.

Recommended aspect ratios / sizes:

| Usage            | Ratio  |
| ---------------- | ------ |
| Product card     | 4 : 3  |
| Product gallery  | 3 : 4  |
| Category / gems  | 1 : 1  |
| Banner / hero    | 16 : 10|

Prefer WebP/AVIF at 2× (retina). `next/image` already emits AVIF/WebP for
raster sources via `next.config.js`.
